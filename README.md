# R Shiny Stock Market Analysis Dashboard

## Project Description
This is an interactive web application built with R and Shiny that allows users to analyze stock market data. Users can input a stock ticker, select a date range, and view a dynamic plot of the stock's adjusted closing price.

## Features
- Fetches real-time stock data from Yahoo Finance.
- Interactive price chart using Plotly.
- User-friendly interface with a custom date range selector.
- Built with a responsive layout that adapts to different screen sizes.

## How to Run This Project
1. Make sure you have R and RStudio installed.
2. Install the required packages: `install.packages(c("shiny", "shinythemes", "quantmod", "ggplot2", "plotly"))`
3. Clone this repository or download the `app.R` file.
4. Open `app.R` in RStudio and click "Run App".

## Technologies Used
- **R:** The core programming language.
- **Shiny:** Web application framework for R.
- **quantmod:** For fetching financial data.
- **ggplot2 & plotly:** For creating interactive visualizations.
